# Requests for Comments (RFCs)

Welcome to the CoreForge RFC space. This directory acts as the pre-implementation workspace for proposing new features, library adapters, and architecture updates.

## Workflow

1. **Create Proposal:** Draft an RFC explaining requirements, proposed API design, and trade-offs.
2. **Review:** Gather feedback and align with maintainers.
3. **Approval:** Once approved, write implementation plan tasks.
4. **Archiving:** After merging the code, document decisions in ADR logs.
