# ADR 0001: Monorepo Architecture

- **Status:** Approved
- **Date:** 2026-08-03

## Context

CoreForge is a reusable multi-package framework. We need to develop, link, test, and publish multiple packages simultaneously while maintaining strict compilation boundaries.

## Decision

We chose **npm workspaces** to orchestrate the packages within a monorepo structure.

## Consequences

- Packages are co-located in the same repository.
- Development builds can refer to local versions using symlinks automatically generated by `npm install`.
